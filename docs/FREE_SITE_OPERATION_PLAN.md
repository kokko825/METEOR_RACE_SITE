# METEOR RACE サイト版 無料運用・調整基盤計画

更新日: 2026-08-14

## 結論

現在のサイトは Cloudflare Workers と D1 に近い構成なので、大部分を再利用できる。
ただし ChatGPT Sites 固有の利用者識別を使用しているため、独自公開前に認証部分を交換する必要がある。

初期公開は月額 0 円を原則とし、無料枠を超えそうなときは自動課金ではなく機能縮退または新規オンライン対戦の受付停止を行う。

## 初期構成

- ソース正本: ユーザー所有の非公開 Git リポジトリ
- 画面/API: Cloudflare Workers と静的配信
- 保存: Cloudflare D1
- 公開URL: Cloudflare の無料サブドメイン
- 独自ドメイン: 希望時のみ購入
- 対戦者認証: 部屋作成時に発行する推測困難な参加鍵
- 現行 ChatGPT Sites: 移行完了まで退避先として維持

## 現状から再利用できるもの

- ゲーム本体とAI
- D1の対戦ルーム保存
- Gitで管理するバランス設定と変更履歴
- CSVの読み書き
- 新規対戦へ設定値を固定する仕組み

## 独自公開前に交換するもの

1. `oai-authenticated-user-email` による利用者識別
2. 一定間隔でルーム全体を取得するオンライン同期
3. ブラウザ内だけに保存されているランク値

## バランス調整の完成形

### ルール設定

- 小・大メテオ初期数
- アイテム総所持数、同種上限
- SHIELD、BOOSTER、HOLO の効果量・継続巡
- BLAST、PULSE の範囲
- ORBITAL GRAVITY の発生周期
- メテオ全消費ボーナス

### AI設定

- 難易度別の先読み量
- 前進評価
- 妨害評価
- アイテム取得評価
- メテオ温存評価
- 後退への減点
- 序盤の直接攻撃への減点
- ゴール直前の阻止評価
- 行動候補の揺らぎ（毎回同じ最善手だけにしない）

### 調整・公開手順

1. `config/game-balance.ts` または `config/site-presentation.ts` を編集
2. AI LAB で全モードを自動試験
3. 完走率、平均手数、引き分け率、先後勝率、アイテム使用率、後退率を比較
4. `npm run check` が通ったらGitHubへ反映
5. 問題時はGitの直前コミットへ戻す

進行中の試合は開始時に保存された設定版を最後まで使用する。

## 無料枠を守る仕組み

- 待機画面の問い合わせ間隔を長くする
- 対戦中だけリアルタイム通信を使用する
- 終了済みルームを定期削除する
- 同一利用者のルーム作成数と操作回数を制限する
- 使用量の段階を「通常・注意・停止」で表示する
- 停止段階ではローカル対戦とAI戦を維持し、新規オンライン対戦だけ止める
- 支払い方法を登録する前に、意図しない従量課金が起きない設定を確認する
